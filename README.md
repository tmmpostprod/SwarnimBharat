## Preview
Open `index.html` in a modern browser.

## Publish
Upload all seven HTML files to the public root of your hosting provider. Keep them together so navigation works.

## Notes
Original page content and visual direction are retained. Navigation placeholders are connected to their corresponding pages, Citizen Honor Roll is included in the shared navigation, and responsive navigation/layout safeguards are added for smaller screens.

The pages load Tailwind CSS, Google Fonts, and Material Symbols from external CDNs, so those assets require an internet connection. Forms, pledge totals, scanner/GPS features, and media submissions may need a backend or service credentials; this static package does not create a database or connect those services.
